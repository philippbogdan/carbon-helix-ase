# Figures and plotted data

Each figure has its own full-width place in the main README. Click it for the vector SVG. The supplied PNGs are 2000 pixels wide; the tallest is 2400 pixels high.

| Figure | Result | Input |
| --- | --- | --- |
| `fig1_error` | Logical error per round at two noise levels | `data/headline.csv` |
| `fig2_cost` | Gates by level and peak qubits | `data/headline.csv`, `data/circuits.json` |
| `fig3_distance` | Restricted fault distances and unfinished whole-circuit searches | `data/distance.json` |
| `fig4_escalation` | Frequency of event-triggered full measurements | `data/interval.json` |
| `fig5_schedule` | Error at each forced full-measurement interval | `data/interval.json` |

Run `./run.sh figures` from the repository root. It checks the four inputs against the saved summary, rebuilds the solver aggregation and circuit accounting, then runs `make_figures.py --force`. It also checks saved decomposition coverage and the 11-fault witness. The exporter in `_export/` is bundled from the scientific-visualization skill so no home-folder tools are needed.

[Data provenance](data/DATA.md) gives raw paths, lookup keys, transformations and refit commands. `data/provenance.json` records input hashes. `exponents.csv` and `intervals.csv` retain the detailed evidence guide's numerical tables. Each regenerated figure also gets an `.export.json` with export settings.

The checked-in images are the supplied originals, unchanged. Their PNG metadata records Matplotlib 3.11.1. Pinned Matplotlib and Pillow match that environment. Font availability, FreeType and platform rendering can still affect pixels; SVG dates and generated element IDs can affect bytes without changing the picture. In the clean-copy check, all five PNGs regenerated byte for byte. All five SVGs matched after normalising dates and element IDs. [reproduction.json](reproduction.json) records hashes, pixel comparisons, versions and the Arial font hash.

## Reproduce the results

From the repository root, with Python 3.12 or newer and a C++17 compiler:

```sh
./run.sh                 # Rebuild circuits, check X and Z, sample and decode
./run.sh figures         # Check data provenance and regenerate all five figures
./run.sh reproduce       # Refit the six headline estimates from raw counts
./run.sh verify          # Refit exponents and schedules; replay scans and failures
```

The commands install pinned packages in a local virtual environment. Frontier builds on first use. [Methods](../RESULTS.md) explain the estimator and time conversion. [Evidence](../EVIDENCE.md) records the checks and limits; [sources](../SOURCES.md) record provenance.
